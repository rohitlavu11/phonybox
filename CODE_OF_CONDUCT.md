# Code of Conduct

Phonybox follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/). In short: be kind, assume good faith, critique code rather than people, and don't harass anyone, in any project space (issues, pull requests, discussions) or when representing the project elsewhere.

## Reporting

If someone's behavior makes you uncomfortable, contact the maintainer privately through the details on [their GitHub profile](https://github.com/rohitlavu11), or use GitHub's [report abuse](https://docs.github.com/en/communities/maintaining-your-safety-on-github/reporting-abuse-or-spam) feature. Reports are kept confidential.

The maintainer may remove, edit or reject comments, commits, code and issues that don't follow this code, and may temporarily or permanently ban contributors, following the Covenant's [enforcement guidelines](https://www.contributor-covenant.org/version/2/1/code_of_conduct/#enforcement-guidelines).
